# Upstream source and attribution

This project is based on [OpenFlight](https://github.com/open-flight/openflight)
by OpenFlight contributors. Its initial source baseline is the official `main`
commit `a3ab081a8abff71fd344d4fd782412d624b99f3f` (2026-11-03). The
upstream `LICENSE` is preserved, as is the upstream Git history. The public
project fork `andersdui22/openflight-face-impact` was created with `main` at
the exact source commit and 1,369 upstream commits. `upstream` remains a
separate Git remote in the local preparation clone.

OpenFlight declares `AGPL-3.0-or-later` in `pyproject.toml`. Forked or modified
versions must retain attribution, notices and the applicable license/source
obligations. This file does not replace `LICENSE`. The binary distribution
notice and source delivery procedure remain to be audited before release.

Experimental source in PRs #245 and #250 and the contributing fork is a
candidate, not incorporated code. See `docs/governance/CANDIDATES.md`. Future
admission requires a scoped gate and source/asset provenance check. No
restricted club mesh or raw personal capture was added here.

The original upstream project documentation and hardware-specific notes stay
in place for provenance. Their presence does not create a radar requirement
for the proposed Windows Face Impact application.
